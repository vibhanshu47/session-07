# Prompt Engineering Session 07: AI as a Hint, Not an Answer

## Overview

This directory contains the deliverables for Session 07. The focus was on solving algorithmic challenges (LeetCode) independently using the "15-Minute Rule," calculating Big-O complexity, and utilizing AI strictly as a reviewer and hint-generator rather than an answer key.

## Objectives Achieved

1. **The 15-Minute Rule:** Enforced a strict discipline of attempting problems independently for 15 minutes before requesting targeted, conceptual AI hints (e.g., LIFO principles for stacks).

2. **Complexity Analysis:** Independently calculated and justified Time and Space complexities (`O(n)`, `O(n²)`, `O(n log n)`) for every solution prior to AI evaluation.

3. **AI Review & Resolution:** Used AI to review edge cases and code clarity, verifying its complexity assessments against manual claims and resolving any discrepancies.

4. **Data Structure Identification:** Recognized when to transition from basic nested loops to auxiliary data structures (Sets, Stacks) for optimal state tracking.

## Repository Contents

### Source Code

- `contains_duplicate.py`: Implementation using Python sets (`O(n)` time).
- `valid_anagram.py`: Sorting-based implementation (`O(n log n)` time).
- `palindrome_number.py`: String slicing implementation (`O(n)` time).
- `valid_parentheses.py`: Stack-based bracket validation (`O(n)` time).
- `twoSum.py`: Nested loop implementation for pair checking.
- `maxProfit.py`: Single-pass minimum value tracking implementation.

### Documentation

- **Hint Logs & Complexity Claims:** Documented workflows proving independent effort, hint usage, and complexity justifications for each problem.
